# DoctorBangla24 Demo

একজন ডাক্তারের জন্য ডেমো ওয়েবসাইট। একটি মাত্র `index.html` ফাইল, কোনো সার্ভার বা ইনস্টল লাগে না।

## যা যা আছে

- **হোম**: ডাক্তারের প্রোফাইল, ফি, সময়সূচি, আজকের সিরিয়ালের অবস্থা, সর্বশেষ ব্লগ।
- **স্বাস্থ্য ব্লগ**: বিভাগ অনুযায়ী লেখা; ডাক্তার প্যানেল থেকে নতুন লেখা প্রকাশ ও মুছে ফেলা যায়।
- **সিরিয়াল নিন**: চেম্বার বা অনলাইন বেছে নিয়ে দিন ও সময় বুক করা; বুকিং আইডি ও সিরিয়াল নম্বর পাওয়া যায়। শুক্রবার বন্ধ, বুক হওয়া সময় বন্ধ থাকে।
- **অনলাইন পরামর্শ**: বুকিং আইডি/মোবাইল দিয়ে রুমে প্রবেশ, ভিডিও প্যানেল (ক্যামেরা প্রিভিউ), চ্যাট।
- **প্রেসক্রিপশন**: ডাক্তার রুম থেকেই ℞ লিখে পাঠান (টেমপ্লেট, ওষুধের সাজেশন, ডোজ ১+০+১ ইত্যাদি); রোগী আইডি দিয়ে প্রেসক্রিপশন প্যাড আকারে দেখতে ও প্রিন্ট করতে পারেন।
- **ডাক্তার প্যানেল** (ডেমো পিন `2468`): আজকের রোগী, অ্যাপয়েন্টমেন্ট নিশ্চিত/বাতিল, ব্লগ, প্রেসক্রিপশনের তালিকা।

## ডেমো দেখানোর ক্রম

1. হোম পেজ দেখান → "সিরিয়াল নিন" এ গিয়ে একটি অনলাইন সিরিয়াল বুক করুন।
2. "ডাক্তার প্যানেল" এ পিন `2468` দিয়ে লগইন → নতুন বুকিং তালিকায় দেখা যাবে।
3. "কল শুরু করুন" → চ্যাট করুন, "ভাইরাল জ্বর" টেমপ্লেট বসিয়ে প্রেসক্রিপশন পাঠান।
4. "রোগীর দৃষ্টিতে দেখুন" চাপুন → রোগী প্রেসক্রিপশন দেখছেন।
5. ব্লগ ট্যাবে নতুন লেখা প্রকাশ করুন।

উপরের "ডেমো ডেটা রিসেট" বোতাম দুবার চাপলে সব নমুনা ডেটা আগের অবস্থায় ফিরে আসে।

## চালানো

`index.html` ব্রাউজারে খুলুন, অথবা GitHub Pages / Netlify তে আপলোড করুন।

## সীমাবদ্ধতা (ডেমো)

- সব ডেটা ব্রাউজারের localStorage এ থাকে; আসল ব্যবহারের জন্য ব্যাকএন্ড (ডেটাবেস, লগইন) লাগবে।
- ভিডিও কল শুধু নিজের ক্যামেরার প্রিভিউ দেখায়; আসল কলের জন্য Jitsi/Agora/WebRTC যুক্ত করতে হবে।
- পেমেন্ট (বিকাশ/নগদ) শুধু নির্বাচনের ঘর; কোনো টাকা কাটা হয় না।
- ডাক্তারের নাম, বিএমডিসি নম্বর ও রোগীরা কাল্পনিক।
