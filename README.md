# Nexine Digital

Nexine Digital একটি ডিজিটাল সার্ভিস প্ল্যাটফর্ম। আমাদের সার্ভিস:

- সফটওয়্যার ও অ্যাপ ডেভেলপমেন্ট
- ওয়েব ডেভেলপমেন্ট
- গ্রাফিক ডিজাইন
- মোশন গ্রাফিক্স
- ভিডিও এডিটিং

## ওয়েবসাইট

`index.html` একটি স্ট্যাটিক ওয়েবসাইট, কোনো বিল্ড স্টেপ লাগে না। ব্রাউজারে সরাসরি খুললেই চলবে,
অথবা GitHub Pages / Netlify-তে হোস্ট করা যাবে।



## লোগো

`assets/logo/` ফোল্ডারে আছে:

- `nexine-mark.svg` / `nexine-mark-512.png` — শুধু আইকন (favicon, প্রোফাইল ছবি)
- `nexine-logo-dark-bg.svg/.png` — গাঢ় ব্যাকগ্রাউন্ডের জন্য
- `nexine-logo-light-bg.svg/.png` — সাদা/হালকা ব্যাকগ্রাউন্ডের জন্য
- `nexine-logo-stacked-*.svg` — উপর-নিচ সাজানো সংস্করণ
